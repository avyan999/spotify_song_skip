# Online Music Streaming Skip Rate Analysis 🎵

A simple data analysis project that analyzes song skip behavior using Spotify song data.

## 📌 Project Overview

This project calculates the skip rate of songs and analyzes whether skip behavior is related to:

- Song popularity
- Number of plays

The project also uses visualizations and correlation analysis to understand the data.
